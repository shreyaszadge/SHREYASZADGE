CSS 
---
Cascading Style Sheet 
- It is used to design your web application
- with the use of css we can apply color , size , 
  borders , background-colors etc ....

Their are three ways to apply css on your website 
-------------------------------------------------
1. InLine css 
   - in this we will use the style attribute and apply the css 
   eg:
       <h1 style="color: brown;">Learn CSS</h1>

2. Internal CSS / Embedded CSS 
   In this we have to use the style tag 
   inside the head and with the help of selectors 
   we will apply the css properties 

   eg:
    <style>
        h1 {
            color: blue;
        }
    </style>
    <h1>Learn CSS</h1>

3.External CSS 
  In this we we create an External file of a CSS 
  with an extension of ".css" and with the help of 
  selectors we apply css and with the help of link 
  tag we import our css file in our project 

  eg:
  style.css -> file created 
  h1 {
    color: blue;
} 

    <link rel="stylesheet" href="style.css">

-----------

on a web page

Can we use the same ID Multiple time ?
-> yes , we can the browser will still 
   renders thye page even if multiple Elements
   have the same id. 

why shouldn't we use the same ID multiple times?
-> Becoz the id is for unique within a document 
   using duplicate id's can create several problem 

   - JavaScript issue 
   - Invalid HTMLS Standards 
   - Accessibility Problem 
   - CSS Maintainace becomes difficult

Attribute Selector 
-----------------
attribute -> which tells you the basic information about the 
             tag and it comes with key-value pair and 
             always written at the starting tag 

syntax: 
[attribute]{
    // apply properties 
}

            border: 2px solid red;

End's with selector($=)
------------------------
Selects elements whose attribute ends with 
specific text 

syntax: 
[attribute$="value"]{
    properties: value;
}

eg:
 [href$=".html"]{
            color: cadetblue;
        }

Contains selector(*=)

contains a specific word/text

}

        }

Descendent Selector
------------------
Selects all elements that are inside another element(at any level)
syntax:
parent child{
    property: value ;
}

eg:
<style>
        div p{
            color: brown;
        }
    </style>
    
    <div>
        <p>Para 1</p>
        <section>
            <p>Para 2</p>
        </section>
    </div>
--------------------------------
Child selector 
---------------
Selects only direct child of an element
syntax:
parent > child {
    property: value;
}

eg:
<style>
        div > p{
            color: brown;
        }

        section > p{
            color: green;
        }
    </style>

    <div>
        <p>Para 1</p>
        <section>
            <p>Para 2</p>
        </section>
    </div>

element1 + element2 {
    property: value;
}

  <style>

            color: blueviolet;
        }
        h2 + p{
            color: blue;

------------------------

BOX-MODEL CSS 
--------------
What is box-model?
-> The CSS Box-model is a fundamental concept that describes how 
   every element on a webpage is structured as a regular box. 
   every HTML element is essentially a box with content , padding 
   border and margin 

   eg:
   photo-frame 
   content - the image itself 
   padding - the mat border areound the photo 
   border - image-frame 
   margin - the space b/w the frames on the wall 

   ------------------------
             margin 
    -----------------------
             border 
    -----------------------
             padding 
    -----------------------
            content 
    -----------------------
             padding
    -----------------------
             border
    -----------------------
              margin 
    -------------------------

----------------

width/height - sets content dimensions 
min-width/ max-width - responsive constraints

Display 
-------
The display property is CSS controls how an element is 
shown on the webpage 
it determines 
-> whether an element takes the full width or 
   only the as much as the content size 
-> whether other element can sit next to it or not 
-> whether the element is visible or not 

------------------------
Display: Block 
-------------
Block elements starts on a new line and takes up 
the full width available i.e 100% of their container width 
they push other elements above or below them 

characteristics 
- always starts on new line 
- take full width by default 
- you can set width and height 
- you can add margin and padding on all sides 

common block elements 
-> div , p , h1-h6 , ul , li , section 
   footer etc.. 

eg: 
<style>
        .block-box{
            display: block;
            background-color: blueviolet;
            width: 100px;
            height: 100px;
            margin: 20px;
            padding: 20px;
        }
    </style>
    
    <span class="block-box">Box 1</span>
    <span class="block-box">Box 2</span>
    <span class="block-box">Box 3</span>
-------------------------------------------
Display: Inline 
---------------
Inline Element donot starts on the new line and 
takes only the requires width as the content size 

characteristics
- doesnot starts on the new line 
- takes only the requires width as the content
- cannot set the width and height 
- padding works but may overlap other elements 

common inline elements 
-> span , a , stong , em , u , b ,i imag 

eg:
    <style>
        .block-box{
            display: inline;
            background-color: blueviolet;
            width: 100px;
            height: 100px;
            /* height and width are not applicable */
            margin: 20px;
            padding: 20px;
        }
    </style>
    
    <div class="block-box">Box 1</div>
    <div class="block-box">Box 2</div>
    <div class="block-box">Box 3</d>

Bost of both elements , element sits next to eachother like

properties
- doesnot starts on the new line

- you can set width and height 
- great for creating navigationmenus , buttons

Display: flex (flexbox)
-----------------------
Display flex is a one-dimensional layout model that 
arranges items in either row or columns 
it is designed to distribute space effeciently and 
align items easily, even when thier sizes are unknown 
or dynamic 

key concepts: 
- flex container : the parent element with display flex 
- flex items : the direct children of the container 
- main axis : the primary direction(row or columns)
- cross axis : the particular direction 

properties on parent 
--------------------
display: flex 
flex-direction: row(default) | columns | row-reverse | columns-reverse 
flex-wrap: wrap | no-wrap | wrap-reverse 
justify-content: flex-start | center | flex-end | space-between 
                 space-around | space-evenly 
align-items: stretch| flex-start | center | flex-end | baseLine 
align-content: stretch | flex-start | center | flex-end | 
               space-between 
gap: px 

properties on child 
-------------------
flew-grow: 0/1/2
flex-shrink: 0/1/2 
flex-basis: intial size 
flex: 1 (shorthand way for flex-grow/shrink/basis)
align-self: auo | flex-start | center | flex-end | stretch 
order: change visual order 

eg:
<style>
        .flex-container{
            display: flex;
            flex-direction: row;
            flex-wrap: wrap;
            justify-content: center;
            align-items: center;

        .flex-item{
            background-color: blueviolet;
            color: white;
            padding: 20px;
            border: 2px solid black;
            min-width: 100px;
            text-align: center;
        }
    </style>

grid item : direct children

grid area: Named rectangular and spanning multiple cells

Position Properties 
---------------------
What is css Positioning? 
-> css positioning determines how an element is placed in the 
   document flow. it controls wheather an element stays in its 
   normal position or moves relative to its normal position or 
   is removed from the flow entirely and positioned based on its 
   parent or viewport 

types 
- static 
- relative
- absolute 
- fixed 
- sticky 

1. Position Static 
-------------------
Static is the default position for all elements 
Elements stay in the normal document flow and appears 
where they naturally belongs in the HTML order. 

- characteristics 
  - follows normal HTML flow 
  - ignores top, left , right bottom and z-index 
  - every element is static by default(you don't need to set it)

eg:
  <style>
        .box{
            width: 100px;
            height: 100px;
            background-color: antiquewhite;
            margin-bottom: 10px;
            text-align: center;
        }
        .static-box{
            position: static;
        }

        .static-box{
            top: 50px;
            
            left: 50px;
        }
    </style>
    
    <div class="box">Box 1</div>
    <div class="box static-box">Box 2</div>
    <div class="box">Box 3</div>
-------------------------------------------------
Position relative 
-----------------
Relative position of an element relates to its normal position 
in the document flow . it moves the element using top ,
left , bottom,  and right from where it would have been normally 

characteristics
- stays in the normal flow(other elements doesnot moves)
- original space is preserved 
- moves based on its original position 
- can use z-index 

eg:
    <style>
        .box{
            width: 100px;
            height: 100px;
            background-color: antiquewhite;
            margin-bottom: 10px;
            text-align: center;
        }
        .relative-box{
            position: relative;
        }

        .relative-box{
            top: 50px;
            left: 200px;
        }
        .negative-relative-box{
            position: relative;
            top: -50px;
            right: -300px;
            background-color: blanchedalmond;
        }
    </style>

flow and positions it's relative to its neareast ancestor 
If no positioned ancestor exists , then its position

characteristics

- positions relative to neareast positioned ancestor
- can overlap other elements 
- uses z-index for stack order

CSS FLEXBOX 
-----------
FlexBox is one of the important css layout system 
it helps you to arrange items in rows or columns ,
align items , distribute space and build responsive 
layout easily

What is flexBox?
-> It is a one-dimensional layout model used to 
   arrange align and distrubute space among the items inside a 
   container eithier in rows or columns

Why do we use flexBox? 
- Easy horizontal and vertical alignments 
- equal spacing b/w items 
- responsive design becomes simple 
- less CSS code 

w/o flexbox 
- difficult to align 
- need to use float , margin and positioning properties 
- responsive layout become complicated 

eg:

    <style>
        .container{
            display: flex;
            flex-direction: row-reverse;
        }
    </style>

        <div> Box 1</div>

        <div> Box 3</div>
        <div> Box 4</div>

    </div>

CSS Transitions Property 
------------------------
CSS Transitions allow you to smoothly change the value of a css 
property over a specified duration instead of changing it
instantaly 
ease: all movements are slow 
ease-in: starting slow and ending is fast 
ease-out: starting fast and end slow 
ease-in-out: start slow mid fast end slow 


eg: 
 <style>
        .btn{
            padding: 10px;
            background-color: lightblue;
            border: none;
            border-radius: 10px;
            transition: all 2s ease-in-out;
        }

        .btn:hover{
            background-color: black;
            color: white;
            letter-spacing: 5px;
            
        }
    </style>
    <button class="btn">Click me</button>
</body>
</html>

CSS Transform Property 
---------------------
The CSS Transform property is used to change the appeareance 
or position of an HTML element w/o affecting the normal layout 
of other elements 

-> Transform allows you to move , rotate , resize or tilt 
   an element 

transform functions 
-------------------
1. translate()
2. translateX()
3. translateY()
4. scale()
5. scaleX()
6. scaleY()
7. rotate()
8. rotateX()
9. rotateY()
10 skew()
11 skewX()
12 skewY()

syntax: 
slector{
    transform: function(value);
}

1. translate()/translateY()/translateX()
------------------------------------------
It is used to move an element from its original position 
eg:
    <style>
        .box{
            width: 100px;
            height: 100px;
            background-color: blue;
            transition: all 2s ease-in-out;
        }
        .box:hover{
            /* transform: translate(100px,100px); */
            transform: translateY(50px);
            width: 200px;
            height: 200px;
        }
    </style>
    
<body>
    <div class="box"></div>
----------------------------------------------------
Scale()
--------
it is a css transform function that changes the size of 
an element 
it can make it bigger (zoom in) or smaller (zoom out) 

syntax: 
transform: scale(x);
transform: scale(x,y) 

x-> controls width in horizontal 
y -> controls width in vertical 

value     effects 
  1        original size 
  2        2x bigger 
  0.5      half the size 
  0        becomes invisible 
  -1       Mirror image + same size 

eg:
 <style>
        img{
            transition: transform 2s ease;
        }
        img:hover{
            transform: scale(-2);  
        }
    </style>
-------------------------------
Transform-origin 
----------------
it will decide from where the 
element should start the transform

eg:
        img:hover{
            transform-origin: top left;
            transform: scale(1.5);  
        }
------------------------------------
3d Scaling 
-----------

an element along three axes X , Y, Z
eg: 
 <style>
        .parent{

            height: 100vh;
            display: flex;
            justify-content: center;

        .child{

            background-color: aquamarine;
            transition: all 2s ease-in-out;
            text-align: center;
            font-size: 40px;
        }
        .child:hover{
            transform: scale3d(-1 , 0.5 , 0.3);
        }
    </style>

rotate()
--------
used to spin/rotate the element 

syntax: 
transfofrm: rotate(angle);

0deg - no rotation 
45deg - 45* clockwise 
90deg - 90* clockwise 
180deg - 180* half turn 
360deg - full circle 
-45deg - 45* anti-clockwise 

positive - clockwise
negative - anti-clockwise 
eg;
 <style>
        img{
            transition: transform 5s ease;
        }
        img:hover{
           transform:  rotate(-45deg);
        }
    </style>

skew()
------
Skew is the css transform property in which it 
tilt the element like a parallelogram 

syntax: 
transform: skew(x-angle)
transform: skew(x-angle , y-angle)

x-angle = horizontal tilt 
y-angle = vertical tilt 

eg:
 img{
            transition: transform 2s ease;
        }
        img:hover{
            transform: skew(20deg,20deg);
        }
