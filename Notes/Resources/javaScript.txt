Variable declaration 
---------------------
1. Var (old way to declare )
   -> functional scope 
   -> re-declare 
   -> we can update it anytime 

   eg:
   <script>
        var a = 10;
        var a = 20;
        console.log("Value " + a);
    </script>

2. let (new way to declare )
   -> block scope 
   -> cannot be redeclare 
   -> we can update or assign the value 

   eg: 
       <script>
        let a = 10;
        // let a ; we cannot re declare it again 
        a = 20;
        console.log("Value " + a);
    </script>

3. const (used for constant values)
    -> we cannot redeclare 
    -> we cannot reasign 
    eg: 
    
        const a = 10;
        // const a ; we cannot re declare it again 
        // a = 20; we cannot reassign
        console.log("Value " + a);
    </script>

HTTP / API 
-----------
HTTP 
----
Hypertext Transfer protocol. It's a set of rules that defines 
how browser (client) and server talk to each other 

API 
---
Application pogramming interface . it is a set of rules that allows two 
application to talk to each other . In web development it's usually a 
URL that returns data 

eg:
http:// or https:// = protocol 
bitzcenter.com = server 
/admin - endpoints 

note -> api returns JSON OBJECT 

HTTP Methods 
------------
GET    - read/get data 
POST   - create new data 
PUT    - update/replace entire data 
PATCH  - update a part of data 
DELETE - delete data 

CRUD -> CREATE READ UPDATE DELETE 

GET 
---
get is used to retrive/read data from the server. 
it doesnot change anything on the server 

http://bitzcenter.com/users -> give all the data 
http://bitzcenter.com/users?age=25&city=Pune 
? = starts query parameters 
age=25 = filter by age 
& = seperate multiple parameters 

POST 
----
Post is used to create new data on the server. 
it sends data in the request body 

PUT 
---
Put is used to update/replace the entire data of a resource. 
you send the complete new version of the data . 

PATCH 
------
Patch is used to update part of the data. 
you send only the fields you want to change 

DELETE 
------
Delete is used to remove the data from the server 

REQUEST 
--------
A request is what the client (browser) sends to the server 
it contains: 
- Method (GET,POST,PUT,PATCH,DELETE)
- URL 
- HEADERS (metadata)
- Body (data - for POST/PUT/PATCH)

eg:
POST https://bitzcenter.com/user 
Content-type : application/json 
Authorization : Bearer Token653116

{
    "name":"Shrey",
    "age" : 30
}

RESPONSE 
---------
A Response is what the server sends back to the client .
it contains 
- status code (200,404 , etc. )
- Headers (metadata)
- Body (data-> JSON)

Status Code 
-----------
status code are 3 digit numbers in the response that tell you 
if the request was successful or not 

Status Code Range: 
1xx      -      informational 
2xx      -      Succes
3xx      -      Redirection 
4xx      -      client error 
5xx      -      server error 

200     ->     ok 
201     ->     creted 
204     ->     No content 

301      ->    Moved permanently 
302      ->    temporary redirect 
304      ->    Not Modified 

400      ->     Bad request (Invalid data)
401      ->     Unauthorized (Not logged in)
403      ->     forbidden (logged in but no permission)
404      ->     Not found (url doesn't exist)
405      ->     Method not allowed (wrong HTTP Methods)
409      ->     conflict (data conflict duplicates)
429      ->     too Many request (rate limited)

500      -> Internal server error (server side error)
502      -> Bad gateway 
503      -> Service Unavailable (Server overloaded)
504      -> Gateway timeout

Promises 
---------
A Promise is a javascript object that represents the eventual completion (success or failure)
of an ASynchronous operation . It is a placeholder for a value that will be availabe later 

3 states 
---------
- Pending  = initial
- fulfilled = success 
- rejected = failure 

eg:

function addStudent(){
    const name = document.getElementById('name').value;
    const age = document.getElementById('age').value; 
    const grade = document.getElementById('grade').value;
    saveStudent(name)
    .then(() => saveAge(age))
    .then(() => saveGrade(grade))
    document.getElementById('output').innerText = "Student Added " + 
    "Name " + name + " Age " + age + " Grade " + grade;
}

function saveStudent(name){
    return new Promise((resolve) => {

Async/Await 
------------
Async/Await is a syntax built on top of promises that let you write 
ASynchronous code that looks and behaves like Synchronous code . 
it makes Async code easier to read and write 

async - declares an async function 
await - waits for a promise to resolve or rejected 

async - it is written before the function as a async function 
        and it always returns promise 

await - pauses the executuion of an async function until a a promise 
        is settled (resolve or rejected)
        it can only be used inside the async function only

class BankAccount {
    constructor(owner,balance = 0){
        if (!owner || owner.length < 2) {
            throw new Error("Invalid owner name");
        }
        if (balance < 0) {
            throw new Error("Balance cannot be negative");
        }

        this.owner = owner;
        this.balance = balance;
        this.createdAt = new Date();
        this.transaction = [];
    }

    deposit(amount){
        if (amount <= 0) {
            throw new Error("Deposit amount must be positive");
        }
        this.balance += amount;
        this.transaction.push({type: "deposite" , amount});
        return this.balance;
    }

    
    withdraw(amount){
        if (amount <= 0) {
            throw new Error("Insufficient Balance");
        }
        this.balance -= amount;
        this.transaction.push({type: "withdraw" , amount});
        return this.balance;
    }
}

Memorization 
-------------\
It is an optimization technique where you cache (store) the results of expensive function 
calls and returns the cached result when the same inputs occur again 

eg:
function square(n){
    return n*n;
}

function memorize(orgFunction){
    const cache = {};

    return function(n){
        if (cache[n] !== undefined) {
        console.log(`Cache Memory ${n}`);
        return cache[n];
        }

        const res = orgFunction(n);
        cache[n] = res;
        return res; 
    };
}

const a = memorize(square);
console.log(a(5));
console.log(a(10));
console.log(a(5));

Debouncing 
-----------
Debouncing ensures that a function is not called until a certain 
amount of time has passed since the last time it was called 
if the event fires again before the delay , the timer resets 

eg:
const input = document.getElementById("searchInput");
const output = document.getElementById("output");


function searchAPI(query){
    console.log(`API CALL FOR ${query}`);
    output.textContent = `Searching for ${query}`;
}


function debounce(func, delay){
    let timer;
    return function(...args){
        clearTimeout(timer);
        timer = setTimeout(() => {
            func(...args);
        },delay);
    };
}
const debounceSearch = debounce(searchAPI, 500);
input.addEventListener('input' ,function(e){
    debounceSearch(e.target.value);
});

throttling 
-----------
throttling ensures that a function is called at most once on a given time interval 
it soesn't wait for events to stop. it just limits how 
often the function runs 


eg:
 <button id="btn">Click</button>
    <div id="output">Clicks: 0</div>


const btn = document.getElementById('btn');
const output = document.getElementById('output');

let count = 0;
function handleClick(){
    count++;
    output.innerHTML = `Count : ${count}`;
    console.log(`Count Button Click ${count}`);
}

function throttle(func , delay){
    let inthrotle;
    return function(...args){
        if (!inthrotle) {
            func(...args);
            inthrotle = true;
            setTimeout(() => {
                inthrotle = false;
            },delay)
        }
    }
}

const t = throttle(handleClick,2000);
btn.addEventListener('click',t);
