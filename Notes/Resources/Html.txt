What is a HTML Tag ?
-> A HTML tag is a keyword enclosed inside 
   angle brackets (< >) that tells 
   the browser how to display the content 
   eg: 
      <h1> Hello Gyuzz </h1>

In HTML their are two types of tags:
1. Paired Tag - in this tag they have both opening and 
                closing tags
2. Unpaired Tag - In this we have only and only single tag 

<h1> -> opening tag 
Hello Guyzz -> content 
</h2> -> closing tag 

What is an element? 
-> opening tag + content + closing tag = element
